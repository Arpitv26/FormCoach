# Asset sources

- Gym footage: copied unchanged from apps/web/public/media/training-hero.mp4, the user-supplied public website header asset. Decorative footage only; no private exercise recordings are included.
- Typography: Archivo Black from apps/web/public/fonts, SIL Open Font License included in composition/assets/OFL-ArchivoBlack.txt. Body uses native sans-serif, resolved by Hyperframes during rendering.
- Music: Happy Beats / Business Moves vol 12 by ende.app, bundled with the installed latent-spaces/brag skill. music.mp3 is a 22-second excerpt with short opening and closing fades. The bundled source README does not specify the exact music redistribution license.
- SFX: click_003.ogg and impactSoft_medium_001.ogg from the brag skill's bundled Kenney library (CC0, per skill asset documentation).
- GSAP: local npm gsap distribution copied into composition/assets/gsap.min.js; its source license header is preserved.
- UI: recreated from this repository; example feedback reflects the user's prior pulldown review. No generated performance scores or measurements.

Animation catalog search was attempted using the official CLI; remote item fetches timed out. Composition uses elementary seek-safe GSAP translations, opacity, and scale. No additional catalog package was installed.
