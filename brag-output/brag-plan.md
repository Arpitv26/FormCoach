# FormCoach — See every rep clearly

## Planning rubric
1. Product: a movement-review demo: upload a workout, review AI observations and measured reps, save a summary.
2. Strongest honest claim: See every rep clearly. Video review makes the next set more intentional; no validated form scores or injury promises.
3. Hook: giant editorial type beside the actual website gym footage, followed by an oversized upload panel.
4. Real UI: recreate the existing exercise selector, Analyze video button, Overview / Reps / Coach tabs, grouped takeaways, Watch links and Save set control from source.
5. Duration: 22 seconds, 1920×1080 at 30fps. Enough to read two concise takeaways.
6. Tone: polished athletic editorial. Black, off-white, green; Archivo Black titles. Motion is decisive, holds are calm.
7. Audio: instrumental music and three quiet UI/reveal accents. No narration. Restrained audio-reactive brand underline.
8. Caption: FormCoach turns a workout video into a clearer next set. Review your reps, get AI coaching, and keep your set summaries in one place.
9. Flow: upload → review → save. No feature montage outside this story.

## Truth and source handling
UI is an animated recreation, with example feedback adapted from the user's observed pulldown review. Small persistent “Demo preview” label identifies the recreation. No fake scores, detection percentages, invented counts, or fabricated chat. Public gym header footage is decorative; it is not presented as the analyzed workout. No private recordings, environment files or backend calls used.
